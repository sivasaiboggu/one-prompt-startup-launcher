Settings

Keys — yours, on your machine only

Nothing here is required. Without a Gemini key the launcher builds everything offline and says so. Keys are stored in this browser's localStorage and are only sent to the service you paste them for.

Free key from Google AI Studio. Live generation uses model gemini-3.8-flash (current for new projects, per Google's docs). If that model returns 404, it tries gemini-3.5-flash-lite once.

Optional. If set, new signups are also written to your Supabase waitlist table (columns: email, slug, created_at). If it is not set, signups stay in this browser — that is the default and it works fine.

Run python3 server.py in this folder. It serves the app on port 8131 and stores signups in data/waitlist.json, so everyone on the same machine sees the same count. The app detects the server automatically; without it, it uses localStorage.
